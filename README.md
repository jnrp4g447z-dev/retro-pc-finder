# Retro-PC-Finder 1985–2010

Eine kleine Webseite für alle, die sich einen Retro-PC bauen wollen: Baujahr und Preisklasse wählen, dann zeigt die Seite passende Prozessoren, Mainboards, Grafik- und Soundkarten für Intel und AMD, dazu das passende Betriebssystem. Außerdem gibt es einen Hardware-Katalog, die Hardware-Generationen (CPUs, GPUs, Soundkarten, Chipsätze), eine Übersicht der Shuttle-XPC-Barebones und eine Liste der PC-Betriebssysteme.

- Eine einzige Datei: `index.html` (kein Build, keine Abhängigkeiten, keine externen Anfragen: die Schriften IBM Plex und VT323 sind eingebettet, Lizenz SIL Open Font License)
- Preise und Termine sind grobe Richtwerte aus eigener Recherche, keine Gewähr.

Privates Hobbyprojekt, nicht kommerziell.
