# Retro-PC-Finder 1985–2010

Eine kleine Webseite für alle, die sich einen Retro-PC bauen wollen: Baujahr und Preisklasse wählen, dann zeigt die Seite passende Prozessoren, Mainboards, Grafik- und Soundkarten für Intel und AMD, dazu einen Hardware-Katalog und die Chip-Generationen.

- Eine einzige Datei: `index.html` (kein Build, keine Abhängigkeiten, außer den Schriften von Google Fonts)
- Preise und Termine sind grobe Richtwerte aus eigener Recherche, keine Gewähr.

Privates Hobbyprojekt, nicht kommerziell.
