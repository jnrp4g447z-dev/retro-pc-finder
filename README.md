# Retro-PC-Finder 1995–2010

Eine kleine Webseite für alle, die sich einen Retro-PC bauen wollen: Baujahr und Preisklasse wählen, dann zeigt die Seite passende Prozessoren, Mainboards, Grafik- und Soundkarten für Intel und AMD, dazu das passende Betriebssystem. Außerdem gibt es einen Hardware-Katalog, die Hardware-Generationen (CPUs, GPUs, Soundkarten, Chipsätze), eine Übersicht der Shuttle-XPC-Barebones, eine Liste der PC-Betriebssysteme und einen Bereich zu Wavetable zum Nachrüsten (Tochterkarten, moderne Nachbauten, externe Module).

- Eine einzige Datei: `index.html` (kein Build, keine Abhängigkeiten, keine externen Anfragen: die Schriften IBM Plex und VT323 sind eingebettet, Lizenz SIL Open Font License)
- Preise und Termine sind grobe Richtwerte aus eigener Recherche, keine Gewähr.
- Die Seite zeigt die Jahre 1995 bis 2010. Frühere Daten sind in der Datei gespeichert, aber ausgeblendet (`YEAR_MIN` im Skript).
- Rechts oben lässt sich das Design wechseln: Klassisch, Stahlblau, BIOS 1999, Windows 3.11 / 98 und Windows XP.
- Fotos und Logos stammen von Wikimedia Commons (freie Lizenzen), der Bildnachweis steht am Ende der Seite.

Privates Hobbyprojekt, nicht kommerziell.
